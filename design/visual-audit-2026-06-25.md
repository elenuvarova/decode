## Что работает — сохранить (это сильные стороны, не трогать)

- **Система доверия проработана по-взрослому.** Бейдж «Calculated, not AI», ссылки на источник в ответах Ask (`p.1`, `p.2 §4 ›`), экран Trust-repair (цитата из документа → исправление → пересчёт), explainer «How Decode works» (AI vs Code). Это редкий уровень для wireframe.
- **Duty-of-care.** `qa-signpost`: детект дистресса → бесплатные службы (StepChange / National Debtline / MoneyHelper) + явная граница «Decode не даёт долговых советов». Согласуется с FCA-границей.
- **Регуляторные дисклеймеры на месте** (`about` → «Not regulated by the FCA», `compare-offers` → «the choice is yours»).
- **Ошибки безупречны.** Семейство error/empty — единый шаблон, блеймлесс-копирайтинг («it's on us», «you haven't been charged», «you haven't used a decode»), всегда есть путь восстановления.
- **Монетизация прозрачна** (`paywall`: таймлайн триала Day 5 / Day 7, «Billed by Apple»; `alerts-inbox`/`radar-settings`: Pro-гейтинг через приглушение, не агрессией).
- **Базовые компоненты переиспользуются** консистентно: list-row (icon □ + title + subtitle + chevron), bottom-sheet с грабером, grouped settings, фильтр-чипы, сегмент-контролы.

## Аудит токенов и шкал (против DESIGN.md)

- **Spacing.** Шкала 4/8/16/24/32/48 в борде и контракте совпадает — претензий нет (на уровне фреймов точные px не проверить, проверять на этапе кода).
- **Типографика.** ⚠ конфликт ramp (находка #4). На самих фреймах иерархия читается хорошо: display-число, h1-заголовки, body, caption — различимы.
- **Цвет.** Grayscale по плану. Риск архитектуры: множество семантических ролей коллапсирует в один и тот же серый (`primary` = `danger` = `trap-high` = `credit-file-yes` = `calculated` = `overdue` → gray-900; `warning` = `trap-med` = `credit-file-cond` = `confidence-check` → gray-600). Это ОК **только если** различие несёт icon/weight/shape — см. находки #2, #3. Сейчас на части экранов носитель различия отсутствует.
- **Радиусы.** Борд показывает sm/default/lg/xl/full — соответствует контракту.

1. **#1 — переэкспорт на единый холст 402×874.** Это снимает мыло на главном экране и выравнивает масштаб по всему набору; один фикс улучшает каждый кадр. Делать первым.

3. **#5–#11 — единообразие** (шапки/back, заголовок overview, CTA-якорь, активный таб, строки settings, выбор плана paywall) — быстрые правки фреймов, большой эффект на воспринимаемое качество.
4. **#4 — свести type-ramp** в DESIGN.md/борде, чтобы дальше код опирался на одну лесенку.
5. **LOW** — гигиена репо и демо-данные, по остаточному принципу.
