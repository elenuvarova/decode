# Decode — Enforcement Pass (2026-06-26)

> Закрытие главного разрыва из [бенчмарка](benchmark-vs-top-companies-2026-06-26.md): «система определена ≠ система применена». Цель — сделать так, чтобы сырое off-token значение **физически нельзя было вставить**, потому что spacing/радиусы/типографика теперь ссылаются на переменные и стили, а не на числа. Выполнено на живом Figma-файле `ZR4wMSgGSbdckASvpiFwIP` через Plugin API (`use_figma`).

## Что было (до прохода)

- **Цвет** — уже привязан к семантическим переменным (primitive→semantic, Wireframe/Light). ✓
- **Spacing / радиусы / типографика** — переменные и text-стили **существовали**, но экраны и компоненты сидели на **сырых числах** (не ссылались). `get_variable_defs` на overview возвращал только цвета.

Инфраструктура уже была полной: коллекция `Spacing` (xs/sm/md/lg/xl/2xl, screen-padding, tap-min, radius-sm/default/lg/xl/full), `Theme` (29 ролей), 9 text-стилей (display/h1/h2/body/body-strong/caption/label/figures/figures-lg). Enforcement = **привязать**, а не создавать.

## Что сделано

Дисциплина: связывал **на мастер-компонентах** (инстансы наследуют) и на скаффолд-фреймах экранов; **внутрь инстансов не заходил**; off-token значения **не двигал** — собирал в отчёт.

| Что | Привязано |
|---|---|
| Паддинги (4 стороны) | **~1310** |
| Гэпы (itemSpacing) | **~449** |
| Радиусы (вкл. pill→radius-full) | **271** |
| Текст-ноды → text-стили | **378** |
| Цвет | (был привязан ранее) |

**Числовой текст** (`£214`, `39.9%`, `£86`…) распознавался эвристикой и привязывался к `figures` / `figures-lg` (**tabular-nums**) — критично для финтеха (суммы должны выравниваться). Все размеры шрифта совпали с 6-ступенчатым ramp (0 off-size) — снап держится.

**Проверка:** `get_variable_defs` на overview теперь возвращает spacing (xs/sm/12/md/20/lg/xl), radius (sm/default/lg/full) и text-стили — раньше только цвета. Визуал не изменился (привязка не меняет значения).

## Решение по шкале — добавлены `space-12` и `space-20`

При связывании всплыло: **12px (×329) и 20px (×152)** массово используются, но не имели токена (шкала прыгала 8→16→24). Оба — на 4-сетке; `space-20` уже фигурировал в `spacing-rhythm.md` как hero-паддинг.

**Выбор:** затокенизировать существующее (значения не меняются), а не снапить 481 отступ к соседям — иначе переверстался бы уже одобренный дизайн. Добавлены `space-12` (12) и `space-20` (20); все 481 связаны. Итоговая шкала: **4 / 8 / 12 / 16 / 20 / 24 / 32 / 48**. Доки `spacing-rhythm.md` + `design-system.md` обновлены (методология: правка дизайна = правка дока).

> Решение обратимо: удалить 2 переменные + снять привязки — если предпочтёшь снап вместо расширения шкалы.

## Остаток (не привязан — намеренно)

Мелкие edge/декоративные значения без токена (≈85 шт.): `2px` микро-гэпы (×24), `34/40px` (×6), малые радиусы грабберов/пилюль `2–7` (×~54). Токены под них засорили бы шкалу — оставлены как есть; решать точечно при желании.

## Эффект на бенчмарк

Enforcement-слой: **C+ → A**. Консистентность стала **свойством системы**, а не обещанием дисциплины: «15px» или 9-й размер шрифта теперь негде взять. Из четырёх слоёв (цвет/spacing/радиус/типографика) enforced все четыре.
