# Decode — Spacing, Rhythm & Grouping

Принципы отступов/группировки/воздуха для мобильного (iOS-first) и как Decode им следует.
Парный документ к токенам в [../DESIGN.md](../DESIGN.md) (шкала spacing там — финальная; здесь — **как её применять**).

## Принципы (mobile GD / UX)

1. **8-pt сетка.** Все отступы кратны 4/8. Off-scale значения (13/14/17/18) ломают ритм — запрещены.
2. **Иерархия тиров, не одно число.** Вертикальный ритм имеет уровни: *внутри элемента* < *внутри группы* < *между секциями* < *между регионами*. Тиры должны быть РАЗЛИЧИМЫ.
3. **Группировка = Gestalt.** Связанное группируется **близостью** (маленький gap) и **общей областью** (карточка/фон). Несвязанное разделяется **большим пробелом**. Правило: gap между секциями ≈ **3×** gap внутри группы — иначе глаз не видит границ групп.
4. **Воздух — это сигнал, не пустота.** Щедрый whitespace вокруг hero-чисел и между секциями = премиальность + читаемость (Apple/Things). Плотность Decode = `spacious`.
5. **Safe-area + thumb-zone.** Контент не под Dynamic Island / home-indicator; нижние CTA и TabBar над `safe-bottom`; tap-target ≥ 44pt, ≥ 8px между тапабельными.
6. **Иерархия размером/пробелом/контрастом**, а не только цветом (тем более в ч/б-вайрфрейме).

## Тиры Decode (применение токенов)

| Тир | Токен | px | Применение |
|---|---|---|---|
| Внутри элемента | `xs` | 4 | иконка ↔ инлайн-текст; супер-тесные пары |
| Внутри группы | `sm` | 8 | заголовок секции ↔ её карточка; строка ↔ строка; label ↔ value |
| Компактный gap/паддинг | `space-12` | 12 | плотные пары (иконка-бокс ↔ текст в строке, вертикальный паддинг кнопки/чипа); промежуточный тир между 8 и 16 |
| Связанные блоки / **паддинг строки-карточки** | `md` | 16 | внутренний паддинг list-row и обычных карточек; gap между связанными блоками; **боковые поля экрана** |
| Hero/feature паддинг | `space-20` | 20 | внутренний паддинг hero/feature-карточек (плотнее секционного 24) |
| **Между секциями** | `lg` | **24** | ← главный рычаг «воздуха»; разделение секций |
| Между регионами | `xl` | 32 | крупные разрывы; перед футером/дисклеймером |
| Empty / onboarding | `2xl` | 48 | пустые состояния, онбординг-разрывы |

> **Шкала дополнена 2026-06-26 (enforcement-проход):** добавлены `space-12` и `space-20` — оба на 4-сетке и **массово используются в макетах** (12px ×329, 20px ×152 на момент связывания). Решение — затокенизировать существующее (значения не менялись), а не снапить 481 отступ к соседям и тем самым переверстать одобренный дизайн. `space-20` уже фигурировал в «Якорных правилах» (hero-паддинг) — просто не был отдельной переменной. Итоговая шкала: **4 / 8 / 12 / 16 / 20 / 24 / 32 / 48**.

**Якорные правила**
- Боковые поля экрана: **16**.
- Верхний паддинг контента под large-title/nav: **16** (не 4 — было).
- **Между секциями: 24** (было 14–18). Внутри секции (header→строки, строка→строка): **8**. Соотношение 1:3.
- Паддинг карточек: **16** (list-row / обычные), **20** (hero/feature). Не 14, не 18.
- Числа/суммы — `tabular-nums`; вокруг hero-числа (`display`) — щедрый воздух (≥16 сверху/снизу).

## Группировка
- **Карточка = common region**: всё внутри одной карточки воспринимается как одно. Связанные поля → одна карточка с паддингом 16.
- **Секция = header(`label`) + карточка(и)**, gap внутри 8; между секциями 24.
- Не разделять связанное линиями, если хватает пробела; не лепить несвязанное в одну карточку.

## Диагноз текущих фреймов (замерено 2026-06-25)

| Рычаг | Было | Цель |
|---|---|---|
| Между секциями | 14–18 | **24** |
| Внутри группы | 8 | 8 ✓ |
| Верхний паддинг (cockpit) | **4** | 16 |
| Паддинг карточек | 14/16/18/20 (разнобой) | 16 / 20 |
| Off-scale | 14, 18, 4 | снять → 8/16/24 |

Корень «мало воздуха»: шкала токенов нормальная, но экраны **не используют верхние тиры** — секции разделены 14–18 вместо 24, верх 4px, off-scale 14/18 размывают ритм (соотношение групп ~1:1.7 вместо 1:3).
