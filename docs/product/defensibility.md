# Decode — защищённость (moat): «зачем мы, если есть ChatGPT/Claude»

**Фаза:** Product analysis · **Дата:** 2026-08-02 · **Входы:** [research/33](../../research/33-scope-and-input-strategy.md), [research/references/competitors-by-logic.md](../../research/references/competitors-by-logic.md)

Ключевой вопрос защищённости: «зачем Decode, если LLM объясняют документы бесплатно?» Ниже — честный ответ (материал для кейса/дека).

## 1. Честно: где LLM нас накрывают
«Приложи документ → объясни» GPT/Claude делают **бесплатно и хорошо**, с цитатами (см. ChatGPT на lease в competitors-by-logic). На «понять текст» мы **не выигрываем** и не продаём это. Более того — **мы сами используем Claude под капотом** (извлечение + Q&A). Рамка «мы против LLM» неверна.

## 2. Переформулировка: мы — прикладной слой поверх commodity-модели
LLM = commodity-вход (электричество). Ров — обвязка вокруг него, делающая его **надёжным и действенным для одной высокоставочной задачи**. «Объяснялка любого документа» = generic GPT-wrapper с нулём выручки ([research/33](../../research/33-scope-and-input-strategy.md)). Ров живёт в вертикали:

1. **Детерминизм на деньгах — «Calculated, not AI».** LLM вероятностен → галлюцинирует числа/APR/total-cost. Там, где ошибка необратима (credit file 6 лет), «скорее всего верно» недостаточно. True-cost считаем **кодом**; LLM — только извлечение/объяснение. Генеративная модель этого структурно не даёт.
2. **Верифицированная UK-вертикаль знаний.** 14 trap-типов, что реально идёт в UK credit file, CPA/DMCC-нюансы, каналы отмены, FCA-периметр. ChatGPT выдаст generic/US-centric/устаревшее. Наш бейдж «credit file: YES/NO» — курируемое определение (см. [knowledge-base-and-rag.md](knowledge-base-and-rag.md)).
3. **Юзер этого не сделает — ров момента.** Тревожный 18–25 не копипастит T&C в ChatGPT и не перепроверяет математику. Продукт = **упаковка намерения в один тап в момент страха** (камера/share → 30с → ответ). Возможность, которую никто не вызывает, ≠ решённая задача.
4. **Watch — LLM stateless/one-shot.** ChatGPT объяснил и забыл. Мы превращаем разовый ответ в **персистентный детерминированный Watch-loop** (см. [watch-architecture.md](../ux/watch-architecture.md)) — вне чат-интерфейса by design.
5. **Доверие/безопасность в регулируемом контексте.** ChatGPT легко скажет «тебе стоит отменить» (финсовет/debt-counselling = FCA-зона) и приободрит галлюцинацией. Мы — внутри FCA-периметра: signposting к StepChange/MoneyHelper, безоценочный тон.
6. **Провенанс = проверяемость.** Каждый факт → строка в *твоём* документе; каждое число посчитано кодом. Важные выводы можно проверить, а не «поверить нейросети».

## 3. Честный риск
LLM дешевеют/умнеют → **ров обязан оставаться в вертикали** (детерминизм + курируемая UK-база + Watch + комплаенс + снятие трения), не в языковом понимании. Как только продаём «объяснялку» — нас съедают.

## 4. Доказательство: качество = harness, не модель (пример Genspark)
Genspark хорош в ресёрче не «потому что Claude под капотом», а из-за **агентной обвязки** (и он мультимодельный). Что даёт качество агентному продукту поверх commodity-модели:
- **планирование / декомпозиция** запроса;
- **живой retrieval** (реальные свежие источники, не память модели);
- **mixture-of-agents** (роутинг под-задач на разные модели + взаимная критика/агрегация);
- **итеративный verify-loop** (сверка утверждений с источником, отсев неподтверждённого);
- **синтез в структурированный артефакт** (формат вывода = часть ценности);
- широкий **toolbelt** + harness-инжиниринг (схемы, цитаты, retry, кэш).

**Вывод-параллель:** Genspark = Claude + research-harness. Decode = Claude + детерминированная денежная математика + UK-trap/credit-file-база + Watch + безопасная подача. В обоих модель — вход, продукт — обвязка.

## 5. Позиционирование одной строкой
> Налоги технически можно сделать калькулятором и PDF налогового кодекса — TurboTax всё равно существует. **Decode = LLM + детерминированная математика + верифицированная UK-база + Watch + безопасная подача, упакованные под один сегмент в момент его страха.** Пересечение (decode × Watch × без bank-link × проверяемость) не даёт ни LLM, ни трекеры.
