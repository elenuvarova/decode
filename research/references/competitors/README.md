## Не сняты (помечено честно)

- **App Store GB для Emma/Snoop** — Apple web стабильно отдаёт «page can't be found»/«error» для этих ID (Bobby загрузился). In-app экраны Emma/Snoop — в Mobbin ([research/13](../../13-mobbin-fintech-home.md)).
- **ReSubs** (прямейшая угроза по механике — AI-extract обязательств из скриншотов без bank link) — добрать на фазе wireframes; разбор в [research/18](../../18-competitor-teardowns.md).
- **Revolut AIR / Starling / NatWest conversational AI** (нормализуют «AI о деньгах», bank-locked) — watch-list в [research/18](../../18-competitor-teardowns.md).
